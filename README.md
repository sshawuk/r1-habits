# Habits: a rabbit r1 creation

Minimal daily habit tracker. Yes/No habits (e.g. No alcohol) and amount habits (e.g. Water, 2 L).

## Controls on the R1
- Scroll wheel: move between habits
- Side button: tick a Yes/No habit, or open an amount habit
- In an amount habit: wheel adds/removes one step; tap the number to type an exact value; side button goes back
- The arrow in the header goes back a day so you can fill in yesterday
- Grid icon: last 7 days and current streaks. Gear icon: add, edit, reorder, delete habits

## Install
1. Host this folder on any HTTPS static host (GitHub Pages is easiest).
2. Open install.html from that host on your phone or computer.
3. Scan the QR with the R1.

Data stays on the device (R1 creationStorage, with localStorage fallback).
